# Mobile Game UX & Player Experience Handbook v1.1 — Markdown Edition

October 2026

This Markdown-only package contains the series index, ten individual handbook guides, and the combined master handbook. It is intended for AI agents, repositories, version control, search, and easy reuse in future game-development projects.

## v1.1 revision highlights

- Dense touch doctrine revised to **mitigate, then validate**; touch occlusion and systematic touch error are addressed explicitly.
- Action controls distinguish intentional execution skill from touchscreen friction; auto-aim is an option, not a universal prescription.
- Cozy/idle/engagement guidance distinguishes meaningful ritual from reward bureaucracy and avoids automatically removing mastered but pleasurable actions.
- The evaluation handbook uses an evidence ladder separating static, scripted, fuzzed, physical-device, human, and telemetry evidence.
- Added **Mobile Game Accessibility & Adaptive Play**.
- Added **Commercial, Live-Service & Connected UX** as a deliberately versioned companion.
- Foundations cover player-facing failure/recovery states without turning into an infrastructure manual.
